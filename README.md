# Академия Пламенея

Портал дистанционного обучения продавцов-стилистов.

- `index.html` — портал (вход по паролю). Раздел для наставника: `index.html#admin`
- `kb-brands.html`, `kb-vstavki.html` — базы знаний брендов и вставок
- `checklist.html` — чек-лист наблюдения
- `bimg/` — иллюстрации
- `config.js` — настройки: адрес Google Apps Script для сохранения прогресса и ответов
